Step operators (record names are short aliases like first/second, not database IDs):
- {"op":"create","record":"first","values":{"canonical_title":"Real test title",...}} supplies all required editable values. Follow with expect covering every editable field before another mutation.
- {"op":"edit","record":"first","values":{"canonical_title":"Revised title"}} changes supplied editable fields; follow with expect covering changed fields.
- {"op":"action","record":"first","action":"canonical_action_id","input":{"canonical_input":"value"}} invokes a valid workflow transition; omit input when none. Follow with expect covering all fields assigned by that action.
- {"op":"expect","record":"first","fields":["canonical_title","canonical_state",...]} inspects these fields in summary or details. Expected values are compiled from prior valid operations; do not write expected-value source code.
- {"op":"remove","record":"second"} followed by {"op":"visible"} proves deletion and isolation.
- {"op":"reload"} remounts the actual App against saved data, then resets declared filters to '*' through their controls. Follow with expect/visible to prove record persistence; filter persistence is not assumed.
- {"op":"filter","filter":"filter_id","value":"canonical_value"} then {"op":"visible"} proves the entire known collection is correctly included/excluded. Create two records differing on the filter before testing it. Reset '*' before operating on a record hidden by a filter.
- {"op":"count","counter":"counter_id"} checks the compiler-derived numeric result. Assert each declared counter at two different values across real mutations.
- {"op":"invalid_create","values":{"canonical_title":"",...},"field":"canonical_title"} must violate the named required/enum rule; checks visible validation, no created row and no saved change.
- {"op":"reject_save","mutation":{"op":"edit","record":"first","values":{"canonical_title":"Rejected change"}}} injects a storage-write failure around a valid create/edit/action/remove operation and checks visible error plus preserved records after remount.
